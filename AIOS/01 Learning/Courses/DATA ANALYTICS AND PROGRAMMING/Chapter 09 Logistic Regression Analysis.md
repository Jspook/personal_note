## Part 1: Macro Architecture & Overview

**การวิเคราะห์ความถดถอยโลจิสติค (Logistic Regression Analysis)** เป็นเทคนิคการวิเคราะห์ทางสถิติและการเรียนรู้ของเครื่อง (Machine Learning) ที่ใช้ศึกษาความสัมพันธ์ระหว่างตัวแปรอิสระ (Independent Variables) กับตัวแปรตาม (Dependent Variable) ที่เป็น **ตัวแปรเชิงคุณภาพ (Categorical Variable)** เพื่อพยากรณ์ความน่าจะเป็นหรือโอกาส (Probability) ที่แต่ละหน่วยข้อมูลจะถูกจัดจำแนกให้อยู่ในกลุ่มใดกลุ่มหนึ่ง แตกต่างจากการถดถอยเชิงเส้น (Linear Regression) แบบดั้งเดิมที่ใช้พยากรณ์ค่าต่อเนื่อง โดย Logistic Regression จะอาศัย **ฟังก์ชันซิกมอยด์ (Sigmoid / Logistic Function)** และการแปลงเป็น **Logit (Log of Odds)** เพื่อจำกัดขอบเขตของผลลัพธ์ให้อยู่ในช่วง $[0, 1]$ เสมอ และประมาณค่าพารามิเตอร์ด้วยวิธี **Maximum Likelihood Estimation (MLE)**

```text
+--------------------------------------------------------------------------------+
|                   Logistic Regression End-to-End Pipeline                      |
+--------------------------------------------------------------------------------+

 1. INPUT DATA
    - Dependent Variable (Y): Binary (0, 1) หรือ Multinomial (> 2 กลุ่ม)
    - Independent Variables (X): Quantitative / Numerical หรือ Categorical
      * หมายเหตุ: ตัวแปรเชิงกลุ่มต้องแปลงเป็น Dummy Variables (k - 1 ตัว) ก่อนเสมอ
                                     ↓
 2. MATHEMATICAL TRANSFORMATION (Link Function)
    - Odds = P(Event) / P(No Event)
    - Logit Link: ln(Odds) = β0 + β1*X1 + β2*X2 + ... + βp*Xp (รูปเชิงเส้น)
    - Logistic Response Function: P(Y=1) = 1 / [1 + exp(-W)] (รูปโค้งตัว S: Sigmoid)
                                     ↓
 3. PARAMETER ESTIMATION
    - Maximum Likelihood Estimation (MLE) ผ่านกระบวนการ Numerical Iteration
    - คำนวณหาเวกเตอร์ β ที่ทำให้ค่า Likelihood สูงสุด (Minimize -2LL)
                                     ↓
 4. MODEL EVALUATION & TESTING
    ├── Badness-of-Fit      : -2 Log Likelihood (-2LL) ยิ่งต่ำยิ่งดี
    ├── Overall Model Test   : Omnibus Test / Model Chi-Square (ทดสอบ H0: β1=...=βp=0)
    ├── Goodness-of-Fit     : Hosmer-Lemeshow Test (ต้องการ Sig > α เพื่อยืนยัน Fit)
    ├── Explained Variance  : Pseudo R² (Cox & Snell R², Nagelkerke R²)
    └── Parameter Significance: Wald Test (ทดสอบทีละตัวแปร H0: βi = 0)
                                     ↓
 5. PREDICTION & INTERPRETATION
    - Classification Table: ตรวจสอบความถูกต้อง (Accuracy, Sensitivity, Specificity)
    - Exp(B) / Odds Ratio: ตีความการเปลี่ยนแปลงของโอกาสเกิดเหตุการณ์ต่อหน่วย X
```

### ตารางเปรียบเทียบ Linear Regression vs. Binary Logistic Regression

| มิติการเปรียบเทียบ | Linear Regression (การถดถอยเชิงเส้น) | Binary Logistic Regression (การถดถอยโลจิสติคสองกลุ่ม) |
| :--- | :--- | :--- |
| **ลักษณะตัวแปรตาม ($Y$)** | ตัวแปรเชิงปริมาณต่อเนื่อง (Continuous Numerical) | ตัวแปรเชิงกลุ่มที่มี 2 ค่า (Binary / Dichotomous: 0 หรือ 1) |
| **เป้าหมายการทำนาย** | พยากรณ์ **ค่าตัวเลขของ $Y$** โดยตรง | พยากรณ์ **โอกาสหรือความน่าจะเป็น ($P$)** ที่จะเกิดเหตุการณ์ $Y=1$ |
| **รูปแบบความสัมพันธ์** | เส้นตรง (Linear Function): $Y = \beta_0 + \beta_1 X + e$ | รูปโค้งตัว S (Sigmoid Curve): $P(Y=1) = \frac{1}{1 + e^{-(\beta_0 + \beta_1 X)}}$ |
| **ขอบเขตค่าพยากรณ์** | $(-\infty, +\infty)$ อาจเกินขอบเขตความเป็นจริงได้ | $[0, 1]$ เสมอ สอดคล้องกับคุณสมบัติของความน่าจะเป็น |
| **ฟังก์ชันเชื่อมโยง (Link Function)** | Identity Link ($Y = W$) | Logit Link: $\ln(\text{Odds}) = \ln\left(\frac{P}{1-P}\right) = W$ |
| **วิธีการประมาณค่าพารามิเตอร์** | Ordinary Least Squares (OLS) หาค่าน้อยสุดของผลบวกกำลังสองคลาดเคลื่อน | Maximum Likelihood Estimation (MLE) ผ่านการคำนวณซ้ำเชิงตัวเลข (Iteration) |
| **การกระจายตัวของความคลาดเคลื่อน** | การแจกแจงแบบปกติ (Normal Distribution, $e \sim N(0, \sigma^2)$) | การแจกแจงแบบทวินาม (Binomial / Bernoulli Distribution) |
| **ดัชนีวัดความแปรปรวนที่อธิบายได้** | ค่าสัมประสิทธิ์การตัดสินใจจริง ($R^2$) | Pseudo $R^2$ (Cox & Snell $R^2$, Nagelkerke $R^2$) |

## Part 2: Module-by-Module Deep Dive

### 2.1 นิยาม ประเภท และข้อสมมติของ Logistic Regression

#### ความหมายและวัตถุประสงค์
> **Logistic Regression** เป็นเทคนิคการวิเคราะห์การถดถอยที่มุ่งเน้นการศึกษาความสัมพันธ์ระหว่างตัวแปรอิสระและตัวแปรตาม เพื่อนำสมการที่ได้ไปพยากรณ์โอกาสที่หน่วยข้อมูลจะจัดอยู่ในกลุ่มใดกลุ่มหนึ่ง

**วัตถุประสงค์หลัก 2 ประการ:**
1. **ศึกษาและประเมินความสัมพันธ์:** เพื่อศึกษาว่าตัวแปรอิสระแต่ละตัวสัมพันธ์กับโอกาสในการเกิดเหตุการณ์ที่สนใจอย่างไร และมีทิศทางอย่างไร
2. **พยากรณ์ความน่าจะเป็น:** เพื่อพยากรณ์โอกาสเกิดเหตุการณ์สำหรับข้อมูลรายใหม่ โดยอาศัยสมการที่สร้างขึ้นจากปัจจัยที่มีผลต่อตัวแปรตาม

#### ประเภทของ Logistic Regression
การจำแนกประเภทขึ้นอยู่กับลักษณะของตัวแปรตาม ($Y$):

| ประเภท | ลักษณะของตัวแปรตาม ($Y$) | ตัวอย่างการประยุกต์ใช้งาน |
| :--- | :--- | :--- |
| **Binary Logistic Regression** | มีได้เพียง 2 ค่า (**Dichotomous Variable**) กำหนดค่าเป็น $1$ (เกิดเหตุการณ์ที่สนใจ) และ $0$ (ไม่เกิดเหตุการณ์) | - การเป็นโรคหัวใจ ($1$=เป็น, $0$=ไม่เป็น)<br>- การซื้อสินค้า ($1$=ซื้อ, $0$=ไม่ซื้อ)<br>- การจ่ายเงินปันผล ($1$=จ่าย, $0$=ไม่จ่าย) |
| **Multinomial Logistic Regression** | เป็นตัวแปรเชิงกลุ่มที่มีมากกว่า 2 ค่า (**Polytomous / Multiclass**) | - ช่องทางการชำระเงินของลูกค้า ($1$=บัตรเครดิต, $2$=Mobile Banking, $3$=E-Wallet, $4$=เงินสด)<br>- ผลการวินิจฉัยโรค (ไม่ป่วย / ขั้นเริ่มต้น / ขั้นรุนแรง) |

#### ลักษณะของตัวแปรอิสระ ($X$)
- **ตัวแปรเชิงปริมาณ (Quantitative / Numerical):** เช่น อายุ, น้ำหนัก, ระดับคอเลสเตอรอล, ความดันโลหิต, รายได้ สามารถนำเข้าสมการได้โดยตรง
- **ตัวแปรเชิงคุณภาพ (Categorical):** เช่น เพศ, สถานะการเป็นโรค, ประวัติครอบครัว ก่อนนำเข้าสมการจะต้องแปลงเป็น **ตัวแปรหุ่น (Dummy Variable)** เสมอ

#### เงื่อนไขและข้อตกลงเบื้องต้น (Assumptions)
1. **ความเป็นอิสระของค่าความคลาดเคลื่อน (Independence of Errors):** ค่าความคลาดเคลื่อนของแต่ละหน่วยตัวอย่างต้องเป็นอิสระต่อกัน (ไม่มี Autocorrelation)
2. **ตัวแปรอิสระไม่มีความสัมพันธ์กันเองสูง (No Multicollinearity):** ตัวแปรอิสระ $X$ แต่ละตัวต้องไม่สัมพันธ์กันเองจนเกินไป หากเกิด Multicollinearity จะทำให้ค่าความคลาดเคลื่อนมาตรฐาน (S.E.) สูงผิดปกติและทดสอบนัยสำคัญคลาดเคลื่อน

### 2.2 โครงสร้างทางคณิตศาสตร์: Sigmoid, Odds, และ Logit

#### ข้อจำกัดของ Linear Regression กับตัวแปรตามแบบ Binary
หากใช้สมการเส้นตรงธรรมดา $Y = \beta_0 + \beta_1 X + e$:
- ค่าที่พยากรณ์ได้อาจมีค่าน้อยกว่า $0$ หรือมากกว่า $1$ ซึ่งขัดต่อหลักการของความน่าจะเป็น ($0 \le P \le 1$)
- ความสัมพันธ์ระหว่างตัวแปรอิสระกับความน่าจะเป็นในการเกิดเหตุการณ์ในความเป็นจริงมีลักษณะเป็นอัตราการเปลี่ยนแปลงที่ไม่คงที่ (ความน่าจะเป็นจะเปลี่ยนช้าที่ส่วนปลายทั้งสองข้าง และเปลี่ยนเร็วตรงช่วงกลาง) ทำให้มีลักษณะเป็น **รูปโค้งตัว S (Sigmoid Curve)**

```text
 P(Y=1)
  1.0 +------------------------------------------+----+ (Upper Asymptote = 1)
      |                                        .*|    
      |                                     . *  |    
      |                                  . *     |     Logistic S-Curve
  0.5 |------------------------------. *---------|     (Inflection point ที่ P = 0.5)
      |                          . *             |    
      |                      . *                 |    
  0.0 +----+-------------------------------------+----+ (Lower Asymptote = 0)
          -X                                    +X
```

#### 1. ฟังก์ชันตอบสนองโลจิสติค (Logistic Response Function)
กำหนดให้ $E(Y) = P(\text{Event}) = P(Y=1)$ แทนความน่าจะเป็นของการเกิดเหตุการณ์ที่สนใจ:

**กรณีตัวแปรอิสระตัวเดียว ($X$ ตัวเดียว):**
$$P(Y=1) = \frac{e^{\beta_0 + \beta_1 X}}{1 + e^{\beta_0 + \beta_1 X}} = \frac{1}{1 + e^{-(\beta_0 + \beta_1 X)}}$$

ความน่าจะเป็นที่จะไม่เกิดเหตุการณ์:
$$P(\text{No Event}) = P(Y=0) = 1 - P(Y=1) = \frac{1}{1 + e^{\beta_0 + \beta_1 X}}$$

**กรณีตัวแปรอิสระหลายตัว ($X_1, X_2, \dots, X_p$):**
$$P(Y=1) = \frac{e^{\beta_0 + \sum_{i=1}^p \beta_i X_i}}{1 + e^{\beta_0 + \sum_{i=1}^p \beta_i X_i}} = \frac{1}{1 + e^{-(\beta_0 + \sum_{i=1}^p \beta_i X_i)}}$$

**อิทธิพลของเครื่องหมายสัมประสิทธิ์ $\beta_1$ ต่อรูปกราฟ:**
- **เมื่อ $\beta_1 > 0$:** เมื่อตัวแปรอิสระ $X$ เพิ่มขึ้น โอกาสที่จะเกิดเหตุการณ์จะ **เพิ่มขึ้น** (กราฟ Sigmoid ชันขึ้นจากซ้ายไปขวา)
- **เมื่อ $\beta_1 < 0$:** เมื่อตัวแปรอิสระ $X$ เพิ่มขึ้น โอกาสที่จะเกิดเหตุการณ์จะ **ลดลง** (กราฟ Sigmoid ลาดลงจากซ้ายไปขวา)

#### 2. อัตราต่อรอง (Odds)
**Odds** หมายถึง **อัตราส่วนระหว่างโอกาสที่จะเกิดเหตุการณ์ต่อโอกาสที่จะไม่เกิดเหตุการณ์**:

$$\text{Odds} = \frac{P(\text{เกิดเหตุการณ์})}{P(\text{ไม่เกิดเหตุการณ์})} = \frac{P(Y=1)}{1 - P(Y=1)} = e^{\beta_0 + \beta_1 X_1 + \dots + \beta_p X_p}$$

**เกณฑ์การตีความค่า Odds:**
- **$\text{Odds} > 1$:** โอกาสเกิดเหตุการณ์ **มากกว่า** โอกาสไม่เกิดเหตุการณ์
- **$\text{Odds} = 1$:** โอกาสเกิดเหตุการณ์ **เท่ากับ** โอกาสไม่เกิดเหตุการณ์ ($P = 0.5$)
- **$\text{Odds} < 1$:** โอกาสเกิดเหตุการณ์ **น้อยกว่า** โอกาสไม่เกิดเหตุการณ์

#### 3. ฟังก์ชันโลจิท (Logit Function)
เนื่องจากสมการ Logistic Response Function มีความสัมพันธ์ในรูปไม่เป็นเชิงเส้น (Non-linear) จึงทำการปรับรูปให้เป็นเชิงเส้นโดยการใส่ลอการิทึมธรรมชาติ ($\ln$) ให้กับค่า Odds ซึ่งเรียกว่า **Logit Function**:

$$\text{Logit}(P) = \ln(\text{Odds}) = \ln\left(\frac{P(Y=1)}{1 - P(Y=1)}\right) = \beta_0 + \beta_1 X_1 + \dots + \beta_p X_p$$

สมการ Logit เป็นสมการใน **รูปเชิงเส้น (Linear in Parameters)** ทำให้สามารถวิเคราะห์ความสัมพันธ์ของตัวแปรอิสระในลักษณะเชิงเส้นได้

#### 4. การประมาณค่าสัมประสิทธิ์ด้วย Maximum Likelihood Estimation (MLE)
ต่างจาก Linear Regression ที่หาผลบวกกำลังสองน้อยที่สุด การวิเคราะห์ความถดถอยโลจิสติคจะใช้ **วิธีภาวะน่าจะเป็นสูงสุด (Maximum Likelihood)** เพื่อประมาณค่าสัมประสิทธิ์ $b_0, b_1, \dots, b_p$ 
- กระบวนการทำงานจะใช้วิธีทางตัวเลขแบบคำนวณซ้ำ (**Iteration**) โดยโปรแกรมจะปรับค่าพารามิเตอร์ไปเรื่อยๆ จนกระทั่งค่า Likelihood Function มีค่าสูงสุด (หรือค่า $-2 \text{ Log Likelihood}$ ลดลงต่ำสุดและนิ่ง ไม่เปลี่ยนแปลงเกินเกณฑ์ที่กำหนด เช่น $< 0.001$)

### 2.3 การแปลงตัวแปรกลุ่มเป็นตัวแปรหุ่น (Dummy Coding)

เมื่อตัวแปรอิสระเป็นตัวแปรเชิงคุณภาพ (Categorical Variables) จำเป็นต้องแปลงข้อมูลให้อยู่ในรูปตัวเลขฐานสอง (0 และ 1) ก่อนนำเข้าสู่สมการ

**หลักการพื้นฐานของ Dummy Coding:**
> หากตัวแปรเชิงกลุ่มมีจำนวน $k$ กลุ่ม จะต้องสร้างตัวแปรหุ่นจำนวน **$k - 1$ ตัวแปร** โดยกลุ่มที่ไม่ได้กำหนดตัวแปรหุ่นจะทำหน้าที่เป็น **กลุ่มอ้างอิง (Reference Group / Baseline)** ซึ่งมีค่าเป็น 0 ในทุกตัวแปรหุ่น

#### ตัวอย่างการ Coding จากเอกสาร (Slide 28)

**1. ตัวแปรรายได้ (Income: 4 กลุ่ม $\rightarrow$ สร้าง 3 Dummy Variables):**
กลุ่มอ้างอิงคือ "ต่ำกว่า 10,000 บาท"

| กลุ่มรายได้ | จำนวนคน | Coding 1 ($D_1$) | Coding 2 ($D_2$) | Coding 3 ($D_3$) |
| :--- | :---: | :---: | :---: | :---: |
| ต่ำกว่า 10,000 บาท (Reference) | 37 | 0 | 0 | 0 |
| 10,000 – 20,000 บาท | 56 | **1** | 0 | 0 |
| 20,001 – 40,000 บาท | 60 | 0 | **1** | 0 |
| มากกว่า 40,000 บาท | 47 | 0 | 0 | **1** |

**2. ตัวแปรที่มี 2 กลุ่ม (Dichotomous: สร้าง 1 Dummy Variable):**
- **เพศ (Gender):** ชาย = 0 (Reference), หญิง = 1
- **เบาหวาน (Diabetes):** ไม่เป็น = 0 (Reference), เป็น = 1
- **กรรมพันธุ์ (Family History):** ไม่มี = 0 (Reference), มี = 1

### 2.4 การทดสอบสมมติฐานและการประเมินความสอดคล้องของแบบจำลอง

#### 1. ค่า $-2 \text{ Log Likelihood}$ ($-2LL$)
- แสดงถึงความคลาดเคลื่อนหรือความไม่สอดคล้องของโมเดลกับข้อมูล (**Badness-of-Fit Statistic**)
- ยิ่งค่า $-2LL$ มีค่าน้อย แสดงว่าแบบจำลองมีความสอดคล้องกับข้อมูลมาก

#### 2. Omnibus Tests of Model Coefficients (Model Chi-Square)
ทดสอบว่าเมื่อนำตัวแปรอิสระเข้าสู่แบบจำลองแล้ว ทำให้แบบจำลองมีประสิทธิภาพในการพยากรณ์ดีกว่าแบบจำลองที่มีเฉพาะค่าคงที่ (Step 0) อย่างมีนัยสำคัญหรือไม่

$$\text{Model } \chi^2 = (-2LL_{\text{Step 0}}) - (-2LL_{\text{Step 1}})$$

- **สมมติฐานการทดสอบ:**
  - $H_0: \beta_1 = \beta_2 = \dots = \beta_p = 0$ (โอกาสที่จะเกิดเหตุการณ์ไม่ขึ้นกับตัวแปรอิสระทั้งหมด)
  - $H_1:$ มี $\beta_i \ne 0$ อย่างน้อย 1 ตัว (โอกาสเกิดเหตุการณ์ขึ้นกับตัวแปรอิสระอย่างน้อย 1 ตัว)
- **เกณฑ์การตัดสิน:** ปฏิเสธ $H_0$ เมื่อค่า $\text{Sig.} < \alpha$ (เช่น $< 0.05$) ซึ่งบ่งชี้ว่าโมเดลโดยรวมมีประโยชน์ในการพยากรณ์อย่างมีนัยสำคัญทางสถิติ

#### 3. การทดสอบความเหมาะสมของโมเดลด้วย Hosmer–Lemeshow Test
ทดสอบความสอดคล้อง (Goodness-of-Fit) ระหว่างค่าความถี่ที่สังเกตได้จริง (Observed) กับค่าความถี่ที่คาดหวังจากโมเดล (Expected) โดยแบ่งกลุ่มตัวอย่างออกเป็น 10 กลุ่มย่อยตามระดับความน่าจะเป็น

- **สมมติฐานการทดสอบ:**
  - $H_0:$ แบบจำลองเหมาะสม มีความสอดคล้องกับข้อมูลจริง (Model fits the data)
  - $H_1:$ แบบจำลองไม่เหมาะสม ข้อมูลเบี่ยงเบนจากโมเดล
- **เกณฑ์การตัดสิน (⚠️ จุดระวังสำคัญ):**
  - **ต้องการให้ไม่สามารถปฏิเสธ $H_0$ ได้ (ยอมรับ $H_0$)** นั่นคือ **$\text{Sig.} > \alpha$ (เช่น $\text{Sig.} > 0.05$)** จึงจะสรุปได้ว่าแบบจำลองมีความเหมาะสม

#### 4. การประเมินความสอดคล้องด้วย Pseudo $R^2$
ใน Logistic Regression ไม่สามารถคำนวณค่า $R^2$ ตามคำนิยามดั้งเดิมของ OLS ได้ จึงใช้ค่าประมาณการความสามารถในการอธิบายความแปรปรวนที่เรียกว่า **Pseudo $R^2$**:
- **Cox & Snell $R^2$:** คำนวณจากอัตราส่วนของ Likelihood มีข้อจำกัดคือค่าสูงสุดจะไม่ถึง 1.0
- **Nagelkerke $R^2$:** พัฒนาต่อจาก Cox & Snell โดยปรับสเกลให้ค่าสูงสุดเป็น 1.0 (100%) นิยมใช้รายงานเป็นหลัก

#### 5. การทดสอบค่าสัมประสิทธิ์รายตัวด้วยสถิติวอลด์ (Wald Test)
ทดสอบว่าตัวแปรอิสระ $X_i$ แต่ละตัวมีผลต่อตัวแปรตามอย่างมีนัยสำคัญทางสถิติหรือไม่

$$\text{Wald} = \left(\frac{b_i}{\text{S.E.}_{b_i}}\right)^2$$

- สถิติทดสอบนี้มีการแจกแจงแบบ Chi-Square โดยมีระดับขั้นความเสรี $df = 1$
- **สมมติฐาน:** $H_0: \beta_i = 0$ เทียบกับ $H_1: \beta_i \ne 0$
- **เกณฑ์การตัดสิน:** ปฏิเสธ $H_0$ เมื่อ $\text{Sig.} < \alpha$ สรุปว่าตัวแปรอิสระตัวนั้นมีอิทธิพลต่อตัวแปรตามอย่างมีนัยสำคัญ

### 2.5 วิธีการคัดเลือกตัวแปรอิสระเข้าสู่โมเดล (Variable Selection Methods)

ในโปรแกรมสถิติ (เช่น SPSS) มีวิธีการเลือกตัวแปรเข้าสมการทั้งหมด 7 วิธีหลัก:

```text
                    วิธีการเลือกตัวแปรอิสระ
                              │
     ┌────────────────────────┴────────────────────────┐
     ▼                                                 ▼
[1] Enter Method                               Stepwise Selection
(นำตัวแปรทั้งหมดเข้าสมการพร้อมกัน)                       │
                                 ┌─────────────────────┴─────────────────────┐
                                 ▼                                           ▼
                         Forward Stepwise                            Backward Stepwise
                      (เริ่มจาก 0 แล้วทยอยเพิ่มตัวแปร)               (เริ่มจากใส่ครบ แล้วทยอยตัดออก)
                                 │                                           │
                    ┌────────────┼────────────┐                 ┌────────────┼────────────┐
                    ▼            ▼            ▼                 ▼            ▼            ▼
                 [2] LR       [4] Wald   [6] Conditional     [3] LR       [5] Wald   [7] Conditional
```

1. **Enter:** นำตัวแปรอิสระทั้งหมดที่กำหนดไว้เข้าสู่สมการพร้อมกันในขั้นตอนเดียว
2. **Forward Stepwise (Likelihood Ratio - LR):** คัดเลือกตัวแปรเข้าทีละตัว โดยพิจารณาตัวแปรที่ทำให้ค่า Likelihood Ratio เปลี่ยนแปลงอย่างมีนัยสำคัญที่สุด
3. **Backward Stepwise (Likelihood Ratio - LR):** ใส่ตัวแปรทั้งหมดเข้าสมการก่อน แล้วทยอยตัดตัวแปรที่ไม่มีนัยสำคัญออกตามเกณฑ์ Likelihood Ratio
4. **Forward Stepwise (Wald):** คัดเลือกตัวแปรเข้าทีละตัวโดยใช้ค่าสถิติ Wald
5. **Backward Stepwise (Wald):** ทยอยคัดตัวแปรออกทีละตัวโดยใช้ค่าสถิติ Wald
6. **Forward Stepwise (Conditional):** คัดเลือกตัวแปรเข้าโดยใช้ความน่าจะเป็นแบบมีเงื่อนไขของตัวแปร
7. **Backward Stepwise (Conditional):** ทยอยคัดตัวแปรออกโดยใช้เกณฑ์ Conditional Parameter

### 2.6 ตัวอย่างการคำนวณด้วยตนเอง (Hand Calculation Example)

#### โจทย์ตัวอย่างจากสไลด์ (Slide 21–22)
> ศึกษาความแตกต่างของการจ่ายเงินปันผลของบริษัทในตลาดหลักทรัพย์ โดยสุ่มตัวอย่างบริษัทที่มีการจ่ายเงินปันผล 20 บริษัท และไม่จ่ายเงินปันผล 20 บริษัท กำหนดตัวแปรดังนี้:
> - **ตัวแปรตาม ($Y$):** $1$ ถ้าปีที่แล้วจ่ายเงินปันผล, $0$ ถ้าปีที่แล้วไม่จ่ายเงินปันผล
> - **ตัวแปรอิสระ ($\text{Size}$):** $1$ ถ้าทุนจดทะเบียน $> 1,000$ ล้านบาท (บริษัทขนาดใหญ่), $0$ ถ้าทุนจดทะเบียน $\le 1,000$ ล้านบาท (บริษัทขนาดเล็ก)
> - ผลการประมาณค่าสัมประสิทธิ์ได้: $b_0 = -1.163$ และ $b_1 = 1.322$
>
> **จงหา:** Logistic Response Function, Odds, และ Logit Function

#### ขั้นตอนการแสดงวิธีทำ

**1. หาสมการ Logistic Response Function:**
$$\hat{P}(Y=1) = \frac{1}{1 + e^{-(b_0 + b_1 \cdot \text{Size})}} = \frac{1}{1 + e^{-(-1.163 + 1.322 \cdot \text{Size})}}$$

- **กรณีบริษัทขนาดเล็ก ($\text{Size} = 0$):**
$$\hat{P}(Y=1) = \frac{1}{1 + e^{-(-1.163)}} = \frac{1}{1 + e^{1.163}} = \frac{1}{1 + 3.1996} = \frac{1}{4.1996} \approx 0.2381 \text{ (23.81\%)}$$
- **กรณีบริษัทขนาดใหญ่ ($\text{Size} = 1$):**
$$W = -1.163 + 1.322(1) = 0.159$$
$$\hat{P}(Y=1) = \frac{1}{1 + e^{-0.159}} = \frac{1}{1 + 0.8530} = \frac{1}{1.8530} \approx 0.5397 \text{ (53.97\%)}$$

**2. หาสมการ Odds:**
$$\text{Odds} = e^{b_0 + b_1 \cdot \text{Size}} = e^{-1.163 + 1.322 \cdot \text{Size}}$$

- **Odds ของบริษัทขนาดเล็ก ($\text{Size} = 0$):**
$$\text{Odds}_0 = e^{-1.163} \approx 0.3125$$
*(โอกาสที่บริษัทเล็กจะจ่ายเงินปันผลคิดเป็น 0.3125 เท่าของโอกาสที่จะไม่จ่าย)*
- **Odds ของบริษัทขนาดใหญ่ ($\text{Size} = 1$):**
$$\text{Odds}_1 = e^{-1.163 + 1.322} = e^{0.159} \approx 1.1723$$
*(โอกาสที่บริษัทใหญ่จะจ่ายเงินปันผลคิดเป็น 1.1723 เท่าของโอกาสที่จะไม่จ่าย)*
- **Odds Ratio ($\text{OR} = \text{Exp}(b_1)$):**
$$\text{OR} = \frac{\text{Odds}_1}{\text{Odds}_0} = \frac{1.1723}{0.3125} = e^{1.322} \approx 3.7509$$
*(บริษัทขนาดใหญ่มีโอกาส (Odds) ในการจ่ายเงินปันผลเป็น **3.75 เท่า** ของบริษัทขนาดเล็ก)*

**3. หาสมการ Logit Function:**
$$\ln(\text{Odds}) = b_0 + b_1 \cdot \text{Size} = -1.163 + 1.322 \cdot \text{Size}$$

#### การแปลผลค่า $\text{Exp}(B)$ (Odds Ratio) อย่างละเอียด (Slide 41, 47)
หลักการตีความค่า $\text{Exp}(b_i) = e^{b_i}$:
1. **ถ้า $b_i > 0 \implies e^{b_i} > 1$:** เมื่อ $X_i$ เพิ่มขึ้น 1 หน่วย จะส่งผลให้ Odds ของการเกิดโรคหัวใจ **เพิ่มขึ้น**
2. **ถ้า $b_i < 0 \implies e^{b_i} < 1$:** เมื่อ $X_i$ เพิ่มขึ้น 1 หน่วย จะส่งผลให้ Odds ของการเกิดโรคหัวใจ **ลดลง**
3. **ถ้า $b_i = 0 \implies e^{b_i} = 1$:** เมื่อ $X_i$ เพิ่มขึ้น 1 หน่วย Odds ของการเกิดโรคหัวใจ **ไม่เปลี่ยนแปลง**

**การแปลผลรายตัวแปรในโมเดล:**
1. **เบาหวาน ($\text{Exp}(B) = 70.693$):** เมื่อควบคุมปัจจัยอื่นให้คงที่ คนไข้ที่ **เป็นโรคเบาหวาน** มีโอกาส (Odds) ในการเป็นโรคหัวใจเป็น **70.693 เท่า** ของคนไข้ที่ไม่เป็นโรคเบาหวาน
2. **กรรมพันธุ์ ($\text{Exp}(B) = 9.697$):** คนไข้ที่ **มีประวัติกรรมพันธุ์** มีโอกาส (Odds) ในการเป็นโรคหัวใจเป็น **9.697 เท่า** ของคนไข้ที่ไม่มีประวัติกรรมพันธุ์
3. **อายุ ($\text{Exp}(B) = 1.098$):** ทุกๆ 1 ปีที่คนไข้อายุเพิ่มขึ้น โอกาส (Odds) ในการเป็นโรคหัวใจจะเพิ่มขึ้นเป็น **1.098 เท่า** (หรือเพิ่มขึ้นร้อยละ $9.8\%$)
4. **ไตรกลีเซอร์ไรด์ ($\text{Exp}(B) = 1.067$):** ทุกๆ 1 หน่วยของไตรกลีเซอร์ไรด์ที่เพิ่มขึ้น โอกาส (Odds) ในการเป็นโรคหัวใจจะเพิ่มขึ้นเป็น **1.067 เท่า** (เพิ่มขึ้นร้อยละ $6.7\%$)
5. **กลูโคส ($\text{Exp}(B) = 0.926$):** ทุกๆ 1 หน่วยของกลูโคสที่เพิ่มขึ้น โอกาส (Odds) ในการเป็นโรคหัวใจจะเป็น **0.926 เท่า** (หรือลดลงร้อยละ $1 - 0.926 = 7.4\%$)

## Part 3: Quick Reference & Exam Cheat Sheet

### Checklist สรุปหัวใจสำคัญก่อนสอบ
- [ ] **Logistic vs. Linear:** จำให้แม่นว่า Logistic ทำนาย "ความน่าจะเป็น (Probability)" ของกลุ่ม ($0 \le P \le 1$) ไม่ใช่ค่าต่อเนื่อง
- [ ] **Sigmoid Curve:** ฟังก์ชัน $P = \frac{1}{1 + e^{-W}}$ ป้องกันไม่ให้ค่าทำนายหลุดออกนอกช่วง $[0, 1]$
- [ ] **Odds Formula:** $\text{Odds} = \frac{P}{1-P}$ (โอกาสเกิด เทียบกับ โอกาสไม่เกิด)
- [ ] **Logit Link:** $\ln(\text{Odds}) = W = \beta_0 + \sum \beta_i X_i$ คือการแปลง Odds ให้เป็นสมการเชิงเส้น
- [ ] **Dummy Coding Rule:** ถ้าตัวแปรเชิงกลุ่มมี $k$ ระดับ ต้องสร้าง Dummy Variables จำนวน $k - 1$ ตัวเสมอ
- [ ] **Omnibus Test:** สถิติ Model $\chi^2$ ต้องการให้ $\text{Sig.} < 0.05$ เพื่อปฏิเสธ $H_0$ ยืนยันว่าโมเดลดีขึ้นจาก Step 0
- [ ] **Hosmer-Lemeshow Trap:** ต้องการให้ $\text{Sig.} > 0.05$ (ยอมรับ $H_0$) เพื่อสรุปว่าโมเดลมีความเหมาะสม
- [ ] **Wald Test:** ทดสอบนัยสำคัญรายตัวแปร ใช้สถิติ $\left(\frac{b}{\text{S.E.}}\right)^2$ ถ้า $\text{Sig.} < 0.05$ แปลว่าตัวแปรนั้นมีนัยสำคัญ
- [ ] **Odds Ratio ($\text{Exp}(B)$):** ถ้ามากกว่า 1 = เสี่ยงเพิ่ม, ถ้าน้อยกว่า 1 = เสี่ยงลด, เท่ากับ 1 = ไม่มีผล

### สรุปสูตรและ Notation ที่สำคัญ

| สัญลักษณ์ / สูตร | ชื่อทางสถิติ | ความหมายและการนำไปใช้ |
| :--- | :--- | :--- |
| $P(Y=1) = \frac{1}{1 + e^{-W}}$ | **Logistic Response Function** | คำนวณความน่าจะเป็นของการเกิดเหตุการณ์ โดย $W = \beta_0 + \sum \beta_i X_i$ |
| $\text{Odds} = \frac{P}{1 - P}$ | **Odds (อัตราต่อรอง)** | อัตราส่วนความน่าจะเป็นเกิดเหตุการณ์ต่อไม่เกิดเหตุการณ์ ($0 \le \text{Odds} < \infty$) |
| $\text{Logit}(P) = \ln(\text{Odds})$ | **Logit Function** | ฟังก์ชันแปลง Odds ด้วย Natural Log เพื่อสร้างความสัมพันธ์เชิงเส้นกับตัวแปรอิสระ |
| $\text{OR} = e^{b_i} = \text{Exp}(B)$ | **Odds Ratio** | อัตราส่วน Odds เมื่อ $X_i$ เพิ่มขึ้น 1 หน่วย เทียบกับก่อนเพิ่ม |
| $\text{Wald} = \left(\frac{b_i}{\text{S.E.}_{b_i}}\right)^2$ | **Wald Statistic** | ทดสอบนัยสำคัญของค่าสัมประสิทธิ์ตัวแปร $X_i$ ($df=1$) |
| $-2LL = -2 \ln(\text{Likelihood})$ | **-2 Log Likelihood** | สถิติวัดความไม่สอดคล้องของโมเดล (Badness of Fit) ยิ่งน้อยยิ่งดี |
| $\text{Model } \chi^2 = (-2LL_0) - (-2LL_1)$ | **Model Chi-Square** | ทดสอบประสิทธิภาพรวมของโมเดลเทียบกับโมเดลว่าง (Omnibus Test) |

### Concept Map

```text
Logistic Regression Architecture
├── 1. Problem Framing
│   ├── Target: Binary (0/1) or Multinomial (>2 categories)
│   └── Goal: Estimate Event Probability P(Y=1) within [0, 1]
│
├── 2. Mathematical Engine
│   ├── Probability Space: 0 <= P <= 1
│   ├── Odds Space: Odds = P / (1 - P)  [0 to +inf]
│   └── Logit Space: ln(Odds) = b0 + b1*X1 + ... [ -inf to +inf ] (Linear!)
│
├── 3. Data Preprocessing
│   ├── Numerical Features: Enter directly
│   └── Categorical Features: Dummy Coding (k - 1 variables, reference = 0)
│
├── 4. Estimation & Model Selection
│   ├── Parameter Estimation: Maximum Likelihood Estimation (MLE via Iterations)
│   └── Selection Strategies: Enter vs Stepwise (Forward/Backward by LR, Wald, Cond)
│
└── 5. Model Diagnostics & Interpretation
    ├── Model Level
    │   ├── Badness of Fit: -2LL (Lowest is best)
    │   ├── Improvement: Omnibus Test (Sig < 0.05)
    │   ├── Goodness of Fit: Hosmer-Lemeshow (Sig > 0.05 is good!)
    │   └── Explanatory Power: Cox & Snell R², Nagelkerke R²
    ├── Variable Level
    │   ├── Significance: Wald Test (Sig < 0.05)
    │   └── Effect Size: Exp(B) = Odds Ratio (OR > 1: เพิ่ม, OR < 1: ลด)
    └── Decision Level
        └── Classification Table: Accuracy, Sensitivity, Specificity
```

## ⚠️ Common Pitfalls & Exam Traps

* **กับดักสับสนระหว่างความน่าจะเป็น ($P$) กับอัตราต่อรอง ($\text{Odds}$):** 
  ความน่าจะเป็นมีค่าระหว่าง $0$ ถึง $1$ เสมอ เช่น $P = 0.8$ แต่ Odds คือ $\frac{P}{1-P} = \frac{0.8}{0.2} = 4$ เท่า (มีค่าตั้งแต่ $0$ ถึง $\infty$) ห้ามตอบค่า Odds เป็นเปอร์เซ็นต์ความน่าจะเป็นเด็ดขาด
* **กับดักการแปลผลค่า Sig ของ Hosmer-Lemeshow สลับกับ Omnibus Test (พบบ่อยที่สุดในข้อสอบ):**
  ในการทดสอบสถิติทั่วไป (เช่น Omnibus, Wald) เรามักมองหา $\text{Sig.} < 0.05$ เพื่อปฏิเสธ $H_0$ แต่สำหรับ **Hosmer-Lemeshow Test สมมติฐาน $H_0$ คือ "โมเดลเหมาะสม" ดังนั้นเราจึงต้องการให้ $\text{Sig.} > 0.05$ เพื่อไม่ให้ปฏิเสธ $H_0$** หาก $\text{Sig.} < 0.05$ จะแปลว่าโมเดลไม่สอดคล้องกับข้อมูล!
* **กับดักการตีความค่า $\text{Exp}(B)$ ที่น้อยกว่า 1:**
  เมื่อค่าสัมประสิทธิ์ $b_i < 0$ ค่า $\text{Exp}(b_i)$ จะมีค่าอยู่ระหว่าง $0$ ถึง $1$ (เช่น $\text{Exp}(B) = 0.926$) ไม่ใช่ค่าติดลบ! หมายถึงเมื่อ $X$ เพิ่ม 1 หน่วย โอกาส (Odds) ในการเกิดเหตุการณ์จะลดลงเหลือ $0.926$ เท่าของเดิม หรือลดลงไป $1 - 0.926 = 7.4\%$
* **กับดัก Dummy Variable Trap:**
  หากตัวแปรเชิงกลุ่มมี $k$ กลุ่ม การใส่ตัวแปรหุ่นครบทั้ง $k$ ตัวเข้าไปในสมการที่มีค่าคงที่ (Constant) จะทำให้เกิดปัญหา Perfect Multicollinearity (ตัวแปรสัมพันธ์กันสมบูรณ์จนไม่สามารถหา Inverse เมทริกซ์ได้) จึงต้องตัดออก 1 กลุ่มเสมอเพื่อเป็นกลุ่มอ้างอิง
* **ความเข้าใจผิดเรื่อง $R^2$ ใน Logistic Regression:**
  Logistic Regression ไม่มีค่า $R^2$ แท้จริงเหมือน OLS Linear Regression ค่า Cox & Snell หรือ Nagelkerke เป็นเพียง **Pseudo $R^2$** เท่านั้น ไม่สามารถแปลผลเป็นสัดส่วนความแปรปรวนของตัวแปรตามได้ตรงไปตรงมาเหมือน Linear Regression
