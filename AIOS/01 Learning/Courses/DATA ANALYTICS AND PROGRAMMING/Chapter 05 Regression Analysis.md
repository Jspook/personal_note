## Part 1: Macro Architecture & Overview

**การวิเคราะห์ความถดถอย (Regression Analysis)** คือเทคนิคทางสถิติที่ใช้ศึกษาความสัมพันธ์ระหว่างตัวแปรตั้งแต่ 2 ตัวขึ้นไป โดยมีวัตถุประสงค์เพื่อ **พยากรณ์ค่าของตัวแปรตัวหนึ่ง (Y) จากตัวแปรอื่น (X)** ที่มีความสัมพันธ์กัน ซึ่งต้องทราบหรือกำหนดค่าของ X ไว้ล่วงหน้า

```text
Regression Analysis — Pipeline:
  1. ข้อมูล Input (X, Y ที่เป็นตัวแปรเชิงปริมาณ)
                |
  2. เขียน Scatter Plot เพื่อพิจารณารูปแบบความสัมพันธ์
                |
       เชิงเส้น?          ไม่ใช่เชิงเส้น?
         |                      |
  Linear Regression       Non-Linear Regression
         |
  3. ประมาณค่า β0, β1 ด้วย Least Squares Method
                |
  4. ทดสอบสมมติฐาน (t-test / F-test / ANOVA)
                |
  5. คำนวณ R² (Coefficient of Determination)
                |
  6. นำสมการไปพยากรณ์ Y เมื่อรู้ค่า X
```

### ตารางเปรียบเทียบ Simple vs. Multiple Linear Regression

| มิติการเปรียบเทียบ | Simple Linear Regression | Multiple Linear Regression |
| :--- | :--- | :--- |
| **จำนวนตัวแปรอิสระ** | 1 ตัว (X เดียว) | 2 ตัวขึ้นไป (X₁, X₂, ..., Xₖ) |
| **สมการ** | $\hat{Y} = b_0 + b_1 X$ | $\hat{Y} = b_0 + b_1 X_1 + b_2 X_2 + ... + b_k X_k$ |
| **ตัวอย่าง** | ยอดขายขึ้นอยู่กับค่าโฆษณา | ยอดขายขึ้นอยู่กับค่าโฆษณาและราคาสินค้า |
| **ความซับซ้อน** | ง่าย ตีความได้ตรงไปตรงมา | ซับซ้อนกว่า ต้องตรวจสอบ Multicollinearity |

## Part 2: Module-by-Module Deep Dive

### 2.1 นิยามและประเภทของ Regression Analysis

**Regression Analysis** แบ่งออกเป็น 2 ประเภทหลักตามรูปแบบความสัมพันธ์:

| ประเภท | คำอธิบาย |
| :--- | :--- |
| **Linear Regression** | ความสัมพันธ์ระหว่าง X และ Y เป็นเส้นตรง |
| **Non-Linear Regression** | ความสัมพันธ์ระหว่าง X และ Y ไม่ใช่เส้นตรง (เช่น เส้นโค้ง Polynomial, Exponential) |

**การพยากรณ์ (Forecasting) 2 แบบ:**

| แบบ | คำอธิบาย |
| :--- | :--- |
| **Time-Series Forecasting** | ใช้ข้อมูลในอดีตของตัวแปรที่ต้องการพยากรณ์มาทำนายค่าในอนาคต |
| **Casual Forecasting** | ใช้ปัจจัย (ตัวแปร X) ที่คาดว่ามีความสัมพันธ์กับตัวแปรที่จะพยากรณ์ |

**ตัวอย่างการนำ Regression ไปใช้จริง:**
- ศึกษาความถี่ในการชมภาพยนตร์ที่ขึ้นอยู่กับรายได้
- ศึกษาผลผลิตข้าวจากปริมาณปุ๋ยที่ใส่
- ศึกษาความสัมพันธ์ของปริมาณความดันโลหิตที่ลดลงกับปริมาณยาลดความดันที่รับประทาน
- ศึกษาความสัมพันธ์ของราคาขายทีวี 50 นิ้วที่มีอิทธิพลต่อจำนวนทีวีที่ขายได้

### 2.2 Simple Linear Regression Analysis

> 💡 **Intuition:** ลองนึกถึงการขาย ice cream — ยิ่งอากาศร้อนมากเท่าไร ยอดขาย ice cream ก็ยิ่งเพิ่มขึ้นเท่านั้น Simple Linear Regression คือเทคนิคการหาความสัมพันธ์ "เส้นตรง" ระหว่างตัวแปร 2 ตัว เพื่อที่เมื่อเรารู้ค่าหนึ่ง (เช่น อุณหภูมิ) เราจะสามารถทำนายค่าอีกตัวหนึ่ง (ยอดขาย) ได้ สิ่งที่สำคัญคือการหา "เส้นตรง" ที่เหมาะสมที่สุด ซึ่งเข้าใจได้จากการเห็น Scatter Plot — ถ้าจุดของข้อมูลกระจายแบบไม่มีแนวเส้นตรงชัดเจน Linear Regression ก็จะไม่ใช่เครื่องมือที่ดี
> [Source: generated — not verified against original document]

**การวิเคราะห์ความถดถอยเชิงเส้นอย่างง่าย (Simple Linear Regression)** คือการศึกษาความสัมพันธ์ระหว่างตัวแปร **2 ตัว** (X และ Y) ที่มีความสัมพันธ์กันในรูปเชิงเส้น โดย X และ Y ต้องเป็น **ตัวแปรเชิงปริมาณ (Quantitative Variable)**

**🧭 ทำความเข้าใจ** _[Source: generated — not verified against original document]_

**แตกวลีสำคัญ:**
- "ตัวแปรตาม (Y)" → ค่าที่เราต้องการคาดการณ์ (เช่น ยอดขาย) — มันขึ้นอยู่กับตัวแปร X
- "ตัวแปรอิสระ (X)" → ค่าที่เราทราบหรือกำหนดได้แล้ว (เช่น อุณหภูมิหรือรายได้) — เราใช้มันในการทำนาย Y
- "ความสัมพันธ์เชิงเส้น" → ความสัมพันธ์ที่อยู่ในรูปเส้นตรง ไม่ใช่โค้งหรือรูปแบบอื่น

**ตัวอย่าง:**
- ✅ ศึกษาการขายทีวี (Y) กับราคาขายสินค้า (X) — ทั้งสองเป็นตัวแปรปริมาณ และอาจมีความสัมพันธ์เชิงเส้น — ใช้ Simple Linear Regression ได้
- ❌ ศึกษาความสัมพันธ์ระหว่างอายุ (X) และจำนวนครั้งที่ดูภาพยนตร์ (Y) ด้วย Linear Regression หากดูจาก Scatter Plot ปรากฏว่าจุดกระจายเป็นรูปเหมือนวงกลม (ไม่ใช่เส้นตรง) — ผลลัพธ์จะผิด เพราะตัวข้อมูลไม่เหมาะสมกับสมมติฐาน Linear
- **ต่างกันตรง:** การเลือกใช้ Simple Linear Regression ต้องมี Scatter Plot ที่ชี้ว่าจุดข้อมูลมีแนวเส้นตรง หากไม่ชัดเจน ต้องใช้วิธีอื่น

**อย่าสับสน:** "Simple Linear Regression" หมายถึง X มีแค่ 1 ตัว เมื่อ X มีหลายตัว ให้เรียก "Multiple Linear Regression" (จะเรียนในบทต่อไป)

**เช็คความเข้าใจ:** ถ้าเรามีข้อมูล 20 เดือน เกี่ยวกับ (งบโฆษณา, ยอดขาย) และต้องการทำนายยอดขายจากงบโฆษณา ควรใช้ Simple Linear Regression หรือ Multiple Linear Regression และเพราะเหตุใด
<details><summary>เฉลย</summary>

ควรใช้ **Simple Linear Regression** เพราะว่า:
- ตัวแปรอิสระ (X) มีเพียง **1 ตัว** = งบโฆษณา
- ตัวแปรตาม (Y) มี 1 ตัว = ยอดขาย
- คำจำกัดความของ Simple คือ X มี 1 ตัว (Simple = ง่าย/เดียว)
- Multiple Linear Regression ใช้เมื่อ X มี 2 ตัวขึ้นไป (เช่น งบโฆษณา + ราคาสินค้า)
</details>

#### สมการถดถอยเชิงเส้นอย่างง่ายของประชากร

$$Y_i = \beta_0 + \beta_1 X_i + e_i \quad ; \quad i = 1, 2, ..., N$$

**ความหมายของพารามิเตอร์:**

| สัญลักษณ์ | ชื่อ | ความหมาย |
| :--- | :--- | :--- |
| $Y$ | ตัวแปรตาม (Dependent Variable) | ค่าที่ต้องการพยากรณ์ ขึ้นอยู่กับ X |
| $X$ | ตัวแปรอิสระ (Independent Variable) | ค่าที่ใช้ทำนาย กำหนดหรือทราบล่วงหน้า |
| $\beta_0$ | จุดตัดแกน Y (Y-intercept) | ค่าของ Y เมื่อ X = 0 (มีหน่วยเดียวกับ Y) |
| $\beta_1$ | ความชัน / สัมประสิทธิ์ถดถอย (Slope / Regression Coefficient) | อัตราการเปลี่ยนแปลงของ Y เมื่อ X เพิ่มขึ้น 1 หน่วย |
| $e_i$ | ความคลาดเคลื่อน (Error Term) | ส่วนต่างระหว่างค่าจริงกับค่าที่สมการทำนาย |

**การตีความ β₁:**

```text
β₁ > 0  →  X และ Y มีความสัมพันธ์ในทิศทางเดียวกัน (X เพิ่ม Y เพิ่ม)
β₁ < 0  →  X และ Y มีความสัมพันธ์ทิศทางตรงข้าม (X เพิ่ม Y ลด)
β₁ ≈ 0  →  X และ Y มีความสัมพันธ์น้อยมาก
β₁ = 0  →  X และ Y ไม่มีความสัมพันธ์กันในรูปเชิงเส้น
```

> 💡 **Intuition:** ลองนึกถึง β₁ ว่าเป็นค่า "การเปลี่ยน" ของ Y เมื่อ X เปลี่ยนไป 1 หน่วย เช่น ในตัวอย่างแชมพูด้านล่าง (X, Y หน่วยหมื่นบาท) ได้ b₁ = 52.57 หมายความว่า ค่าโฆษณาเพิ่ม 1 หน่วย (10,000 บาท) ยอดขายเพิ่ม 52.57 หมื่นบาท (525,700 บาท) ถ้า β₁ ติดลบ หมายความว่า X และ Y ไป "ทิศทางตรงข้าม" (เช่น ราคาทีวียิ่งสูง จำนวนทีวีที่ขายได้ยิ่งลด)
> [Source: generated — not verified against original document]

#### ข้อสมมติของ Regression Analysis

> 💡 **Intuition:** ลองนึกว่าสมการถดถอยเหมือนเครื่องมือวัดที่ต้องตั้งค่าเงื่อนไขให้ถูกก่อนใช้ ข้อสมมติคือเงื่อนไขการตั้งค่านั้น ถ้าเงื่อนไขไม่เป็นจริง ค่า β และผลทดสอบ t/F ที่ได้ยังคำนวณออกมาได้ปกติ แต่จะไม่น่าเชื่อถือ จุดที่อุปมาจะพัง: ข้อสมมติไม่ได้ตั้งค่าเองได้ เราต้องตรวจจากข้อมูลและ residual หลังคำนวณ
> [Source: generated — not verified against original document]

1. ค่า X ต้องเป็นค่าที่กำหนดไว้ล่วงหน้า (Fixed)
2. $e_i$ และ $e_j$ เป็นอิสระต่อกัน (Independent)
3. $e_i$ มีการแจกแจงแบบปกติ (Normal Distribution) ที่มีค่าเฉลี่ย = 0 และค่าแปรปรวน = $\sigma^2$

**🧭 ทำความเข้าใจ** _[Source: generated — not verified against original document]_

**แตกวลีสำคัญ:**
- "Fixed X" → ค่า X ถูกกำหนดหรือทราบล่วงหน้า ไม่ได้มีความไม่แน่นอนปนมาในตัวแปรอิสระ
- "$e_i$ และ $e_j$ เป็นอิสระต่อกัน" → ความคลาดเคลื่อนของการสังเกตหนึ่งไม่ได้บอกความคลาดเคลื่อนของอีกการสังเกตหนึ่ง
- "$e_i \sim N(0, \sigma^2)$" → ความคลาดเคลื่อนกระจายรอบเส้นแบบสมมาตร ค่าเฉลี่ยเป็น 0 และการกระจายคงที่

**ตัวอย่าง:**
- ✅ งบโฆษณาแต่ละเดือนถูกตั้งไว้เอง (X กำหนดได้) และความคลาดเคลื่อนของเดือนนี้ไม่เกี่ยวกับเดือนก่อน — ข้อสมมติน่าจะพอใช้ได้
- ❌ ยอดขายรายวัน 30 วัน ซึ่งวันนี้มักใกล้เคียงกับเมื่อวาน — ความคลาดเคลื่อนของวันนี้ผูกกับเมื่อวาน จึงไม่เป็นอิสระต่อกัน (ข้อมูลที่เรียงตามเวลาลักษณะนี้ต้องระวังเป็นพิเศษ)
- **ต่างกันตรง:** ตรวจว่าความคลาดเคลื่อนของแต่ละจุดเป็นอิสระต่อกันหรือมีลำดับ/รูปแบบต่อเนื่องหรือไม่

**อย่าสับสน:** "ข้อสมมติ" หมายถึงเงื่อนไขที่ต้องตรวจเพื่อให้การสรุปผลเชื่อได้ ไม่ได้หมายถึงผลลัพธ์ที่เราอยากให้ออกมา ข้อมูลที่ไม่ผ่านข้อสมมติไม่ได้แปลว่าการคำนวณผิด แต่แปลว่าต้องระวังการสรุปผลมากขึ้น

**เช็คความเข้าใจ:** ยอดขายรายวัน 30 วัน โดยยอดของวันนี้มักใกล้เคียงกับยอดเมื่อวาน ข้อสมมติข้อใดน่าจะถูกละเมิด และเพราะเหตุใด

<details><summary>เฉลย</summary>

ข้อ 2 ($e_i$ และ $e_j$ เป็นอิสระต่อกัน) น่าจะถูกละเมิด เพราะความคลาดเคลื่อนของวันนี้สัมพันธ์กับความคลาดเคลื่อนของเมื่อวาน (ข้อมูลเป็นลำดับเวลา) ข้อ 1 และ 3 ไม่ได้เป็นประเด็นหลักจากโจทย์นี้

### 2.3 การประมาณค่าพารามิเตอร์ด้วย Least Squares Method

> 💡 **Intuition:** ลองนึกว่าเรามีกลุ่มจุดที่กระจายอยู่ และต้องลากเส้นตรงที่จะ "พอดี" กับจุดทั้งหมดให้มากที่สุด Least Squares Method คือการหาเส้นตรงนั้นด้วยการ "ลดระยะห่างให้น้อยที่สุด" โดยเฉพาะการลดผลบวกของ (ระยะห่างแนวตั้งระหว่างจุดกับเส้น ยกกำลังสอง) หมายความว่าเส้นตรงที่เราหาได้จะเป็นเส้นที่ "ดีที่สุด" ในแง่ที่ว่าผลรวมความคลาดเคลื่อนยกกำลังสองน้อยที่สุด
> [Source: generated — not verified against original document]

สมการถดถอยของตัวอย่าง (Sample Regression Line) คือ:

$$\hat{Y} = b_0 + b_1 X$$

โดย $b_0$ และ $b_1$ เป็นค่าประมาณของ $\beta_0$ และ $\beta_1$ ที่คำนวณด้วยวิธี **Least Squares Method** เพื่อให้ผลบวกของค่าคลาดเคลื่อนยกกำลังสองมีค่า **น้อยที่สุด**

**🧭 ทำความเข้าใจ** _[Source: generated — not verified against original document]_

**แตกวลีสำคัญ:**
- "ผลบวกของค่าคลาดเคลื่อนยกกำลังสอง" → $\sum e_i^2 = \sum (Y_i - \hat{Y}_i)^2$ = ผลบวกของ (ค่าจริง - ค่าคาดการณ์) ยกกำลังสอง ยกกำลังสองเพื่อให้ error ทั้งค่าบวก (under-prediction) และค่าลบ (over-prediction) กลายเป็นค่าบวก จึงไม่หักล้างกัน
- "Least" → น้อยที่สุด = หาค่า b₀, b₁ ที่ทำให้ผลบวกนี้มีค่าน้อยสุด

**ตัวอย่าง:**
- ✅ จากตัวอย่างในข้อความ (ยอดขาย Shampoo): ด้วยการใช้สูตร Least Squares Method ได้ b₁ = 52.57, b₀ = 46.48 ซึ่งให้สมการ $\hat{Y} = 46.48 + 52.57X$ — ไม่มีเส้นตรงอื่นที่ให้ SSE ต่ำกว่านี้กับข้อมูลชุดนี้
- ❌ หากเราลากเส้นตรงแบบสุ่มที่ไม่ใช่ Least Squares (เช่น เพียงลากผ่านสองจุดแรกเท่านั้น) SSE (ผลบวกของส่วนต่างยกกำลังสอง) จะมากกว่า หรืออย่างดีที่สุดก็เท่ากับเส้น Least Squares
- **ต่างกันตรง:** Least Squares Method เป็นวิธีที่ "ลดความคลาดเคลื่อนให้น้อยสุด" ตามนิยามทางคณิตศาสตร์ ไม่ใช่วิธีลากเส้นแบบ "ประมาณ ๆ" 

**อย่าสับสน:** "Least Squares" ไม่ใช่ "Least Error" — ความแตกต่างคือเรายกกำลังสองมันก่อน เพื่อให้ error ที่เป็นค่าลบไม่หักล้างกับค่าบวก (ถ้าบวก error ตรง ๆ เส้นที่แย่มากก็อาจได้ผลรวมใกล้ 0)

**เช็คความเข้าใจ:** ถ้าข้อมูลของคุณมี 2 จุด: (X=1, Y=10) และ (X=2, Y=20) เส้นตรง $\hat{Y} = 5 + 5X$ และเส้นตรง $\hat{Y} = 0 + 10X$ เส้นไหนที่ Least Squares Method จะเลือก
<details><summary>เฉลย</summary>

ต้องคำนวณ Sum of Squared Errors (SSE) สำหรับแต่ละเส้น:

**สำหรับ $\hat{Y} = 5 + 5X$:**
- ที่ X=1: ค่าจริง Y=10, ค่าคาดการณ์ $\hat{Y}=5+5(1)=10$, ความผิดพลาด $e_1 = 10-10=0$, $e_1^2=0$
- ที่ X=2: ค่าจริง Y=20, ค่าคาดการณ์ $\hat{Y}=5+5(2)=15$, ความผิดพลาด $e_2 = 20-15=5$, $e_2^2=25$
- SSE = 0 + 25 = 25

**สำหรับ $\hat{Y} = 0 + 10X$:**
- ที่ X=1: ค่าจริง Y=10, ค่าคาดการณ์ $\hat{Y}=0+10(1)=10$, ความผิดพลาด $e_1 = 10-10=0$, $e_1^2=0$
- ที่ X=2: ค่าจริง Y=20, ค่าคาดการณ์ $\hat{Y}=0+10(2)=20$, ความผิดพลาด $e_2 = 20-20=0$, $e_2^2=0$
- SSE = 0 + 0 = 0

**เส้นที่ Least Squares Method เลือก:** $\hat{Y} = 0 + 10X$ เพราะมี SSE=0 ต่ำสุด (ผ่านจุดทั้งสองพอดี)
</details>

**สูตรคำนวณ:**

$$SS_{XY} = \sum x_i y_i - \frac{\sum x_i \sum y_i}{n}$$

$$SS_{XX} = \sum x_i^2 - \frac{(\sum x_i)^2}{n}$$

$$b_1 = \frac{SS_{XY}}{SS_{XX}}$$

$$b_0 = \bar{y} - b_1 \bar{x}$$

#### ตัวอย่างคำนวณ: ยอดขายกับค่าโฆษณาทางวิทยุ

**โจทย์:** ผู้จัดการบริษัทขายแชมพูเชื่อว่ายอดขายขึ้นอยู่กับค่าโฆษณาทางวิทยุ เก็บข้อมูล 10 เดือน ดังนี้:

| :---: | :---: | :---: | :---: | :---: | :---: |
| 1 | 1.2 | 101 | 121.2 | 1.44 | 10,201 |

| 3 | 1.0 | 110 | 110.0 | 1.00 | 12,100 |
| 4 | 1.3 | 120 | 156.0 | 1.69 | 14,400 |
| 5 | 0.7 | 90 | 63.0 | 0.49 | 8,100 |
| 6 | 0.8 | 82 | 65.6 | 0.64 | 6,724 |
| 7 | 1.0 | 93 | 93.0 | 1.00 | 8,649 |

**คำนวณ:**

```
SS_XX = 9.28 - (9.4² / 10) = 9.28 - 8.836 = 0.444
SS_XY = 924.8 - (9.4 × 959 / 10) = 924.8 - 901.46 = 23.34

b₁ = SS_XY / SS_XX = 23.34 / 0.444 = 52.57 (หมื่นบาท = 525,700 บาท)

ȳ = 959/10 = 95.9
x̄ = 9.4/10 = 0.94

```

$$\hat{Y} = 46.48 + 52.57X$$

### 2.4 การทดสอบสมมติฐานเกี่ยวกับ β₁

> 💡 **Intuition:** หลังจากเราหาเส้นตรงได้แล้ว ยังต้องตรวจสอบว่า "เส้นตรงนี้มีความหมายจริง ๆ หรือเป็นเพียงแค่เรื่องบังเอิญจากข้อมูลที่เราเก็บมา" เช่น ถ้าเราสุ่มจำนวนรองเท้าและเกรดสอบวิทยาศาสตร์ของนักเรียน 10 คน อาจพบความสัมพันธ์บ้าง แต่ความสัมพันธ์นี้คือบังเอิญ ไม่ใช่ความสัมพันธ์จริง การทดสอบสมมติฐาน β₁ ช่วยเราตรวจสอบว่า "ความสัมพันธ์ที่เห็นมานี้แข็งแรงพอจะเชื่อถือได้หรือไม่"
> [Source: generated — not verified against original document]

การทดสอบว่า X และ Y มีความสัมพันธ์กันในลักษณะเชิงเส้นหรือไม่

**สมมติฐาน:**
- $H_0: \beta_1 = 0$ (X และ Y ไม่มีความสัมพันธ์เชิงเส้น)
- $H_1: \beta_1 \neq 0$ (X และ Y มีความสัมพันธ์เชิงเส้น)

**🧭 ทำความเข้าใจ** _[Source: generated — not verified against original document]_

**แตกวลีสำคัญ:**
- "$H_0: \beta_1 = 0$" → สมมติฐานว่างคือ "ไม่มีความสัมพันธ์เชิงเส้น" = ความชันเป็นศูนย์ = ไม่ว่า X เปลี่ยนมากหรือน้อย Y ก็ไม่เปลี่ยนแปลง
- "t-statistic" → ค่าทดสอบที่ได้จากการเปรียบเทียบ (b₁ ที่ประมาณได้) กับ (ความคลาดเคลื่อนมาตรฐานของ b₁) — ถ้า b₁ มีค่ามากเทียบกับความไม่แน่นอน ค่า t จะสูง
- "critical value / t-table" → ค่าวิกฤต $t_{\alpha/2,\,n-2}$ จากตาราง ที่เราเปรียบเทียบกับ $|t_{cal}|$ เพื่อตัดสินใจว่าจะปฏิเสธ $H_0$ หรือไม่

**ตัวอย่าง:**
- ✅ จากตัวอย่างยอดขาย Shampoo: $t_{cal} = 5.12 > t_{critical} = 2.31$ → ปฏิเสธ $H_0$ → สรุปว่า β₁ ≠ 0 → X (ค่าโฆษณา) และ Y (ยอดขาย) มีความสัมพันธ์เชิงเส้นอย่างมีนัยสำคัญที่ α = 0.05 (นัยสำคัญบอกว่าไม่น่าใช่บังเอิญ ส่วนความแรงของความสัมพันธ์ดูจาก R²)
- ❌ ถ้า $t_{cal} = 0.5 < t_{critical} = 2.31$ → ไม่ปฏิเสธ $H_0$ → X และ Y อาจไม่มีความสัมพันธ์ที่มีนัยสำคัญ (หรือความสัมพันธ์ที่เห็นมาอาจเป็นบังเอิญ)
- **ต่างกันตรง:** ความแตกต่างระหว่าง "ปฏิเสธ $H_0$" กับ "ไม่ปฏิเสธ $H_0$" คือการตัดสินใจว่าความสัมพันธ์ที่เห็นมามีนัยสำคัญหรือไม่

**อย่าสับสน:** "ปฏิเสธ $H_0$" ≠ "พิสูจน์ว่า $H_1$ เป็นจริง" — เราพูดว่า "มีหลักฐานเพียงพอที่จะปฏิเสธสมมติฐานว่างที่ระดับนัยสำคัญ 0.05" ไม่ใช่ "X และ Y ต้องสัมพันธ์กัน 100%"

**เช็คความเข้าใจ:** ถ้า $t_{cal} = 1.5$ และ $t_{critical} (α=0.05) = 2.31$ เราควรสรุปว่าอะไร
<details><summary>เฉลย</summary>

เพราะว่า $t_{cal} = 1.5 < t_{critical} = 2.31$ 

**เราไม่ปฏิเสธ $H_0$** 

ความหมาย: ยังไม่มีหลักฐานที่แข็งแรงพอที่จะสรุปว่า β₁ ≠ 0 ที่ระดับนัยสำคัญ 0.05 อาจเป็นเพราะความสัมพันธ์อ่อนจริง หรือข้อมูลน้อยเกินไป (ไม่ปฏิเสธ $H_0$ ≠ พิสูจน์ว่า β₁ = 0)
</details>

**สถิติทดสอบ:**

$$t = \frac{b_1}{S_{b_1}} = \frac{b_1}{S / \sqrt{SS_{XX}}}$$

โดยที่:

$$S^2 = \frac{SS_{YY} - b_1 \cdot SS_{XY}}{n - 2}$$

**เขตปฏิเสธ $H_0$:** ปฏิเสธ $H_0$ ถ้า $|t_{cal}| > t_{\alpha/2, n-2}$

**ผลการคำนวณจากตัวอย่าง:**

```
SS_YY = 93569 - (959² / 10) = 93569 - 91968.1 = 1600.9
S² = (1600.9 - 52.57 × 23.34) / 8 = (1600.9 - 1226.93) / 8 = 373.97 / 8 = 46.74
S = 6.84

t_cal = 52.57 / (6.84 / √0.444) = 52.57 / 10.26 = 5.12
t_critical (α=0.05, df=8) = 2.31

5.12 > 2.31  →  ปฏิเสธ H₀
สรุป: X และ Y สัมพันธ์กันในลักษณะเชิงเส้น ที่ระดับนัยสำคัญ 0.05
```

### 2.5 การทดสอบด้วย ANOVA (Analysis of Variance)

> 💡 **Intuition:** ลองนึกว่าความผันแปรของยอดขาย (Y) ทั้งหมดเป็นเค้กก้อนเดียว เราแบ่งเค้กออกเป็นสองส่วน คือส่วนที่งบโฆษณา (X) อธิบายได้ (SSR) กับส่วนที่ยังเหลือเป็นความคลาดเคลื่อน (SSE) ถ้าส่วนแรกใหญ่กว่าส่วนหลักมาก แปลว่า X มีผลจริง ANOVA F-test คือการเปรียบเทียบสองส่วนนี้หลังปรับด้วยองศาอิสระ จุดที่อุปมาจะพัง: F ไม่บอกทิศทางของความสัมพันธ์ (บวกหรือลบ) และไม่บอกความแรงของความสัมพันธ์ บอกได้เพียงว่ามีนัยสำคัญหรือไม่
> [Source: generated — not verified against original document]

อีกวิธีหนึ่งในการทดสอบ β₁ คือการใช้ **การวิเคราะห์ความแปรปรวน (ANOVA)**

**สมมติฐาน:**
- $H_0: \beta_1 = 0$
- $H_1: \beta_1 \neq 0$

**สถิติทดสอบ:** $F = \frac{MSR}{MSE}$

**ตาราง ANOVA:**

| แหล่งความผันแปร | DF | SS | MS = SS/DF | F |
| :--- | :---: | :---: | :---: | :---: |
| ความถดถอย (Regression) | 1 | SSR | MSR | MSR/MSE |
| ความคลาดเคลื่อน (Error) | n-2 | SSE | MSE | |
| ผลรวม (Total) | n-1 | SST | | |

**สูตรคำนวณ SS:**

$$SSR = \frac{SS_{XY}^2}{SS_{XX}}$$

$$SST = SS_{YY} = \sum y_i^2 - \frac{(\sum y_i)^2}{n}$$

$$SSE = SST - SSR$$

**ผลการคำนวณจากตัวอย่าง:**

| แหล่งความผันแปร | DF | SS | MS | F |
| :--- | :---: | :---: | :---: | :---: |
| ความถดถอย | 1 | 1226.93 | 1226.93 | 26.24 |
| ความคลาดเคลื่อน | 8 | 373.97 | 46.75 | |
| ผลรวม | 9 | 1600.90 | | |

```
F_cal = 26.24 > F_critical (α=0.05, df=1,8) = 5.32
→ ปฏิเสธ H₀
สรุป: X และ Y สัมพันธ์กันในลักษณะเชิงเส้น ที่ระดับนัยสำคัญ 0.05
```

> **ความสัมพันธ์ระหว่าง t-test และ F-test:** ในกรณี Simple Regression ผลลัพธ์เหมือนกัน โดย $F = t^2$ (26.24 ≈ 5.12²)

**🧭 ทำความเข้าใจ** _[Source: generated — not verified against original document]_

**แตกวลีสำคัญ:**
- "SSR (Regression)" → ส่วนของความผันแปรของ Y ที่โมเดลอธิบายได้ (ในตัวอย่างคือ 1226.93)
- "SSE (Error)" → ส่วนของความผันแปรของ Y ที่โมเดลอธิบายไม่ได้ (ในตัวอย่างคือ 373.97)
- "F = MSR / MSE" → อัตราส่วนระหว่างส่วนที่อธิบายได้กับส่วนที่อธิบายไม่ได้ เมื่อปรับด้วยองศาอิสระแล้ว ถ้ามากกว่า F_critical แปลว่า X มีผลจริง

**ตัวอย่าง:**
- ✅ ตัวอย่างนี้ F_cal = 26.24 > F_critical = 5.32 → ปฏิเสธ H₀ เพราะ SSR (1226.93) ใหญ่กว่า SSE (373.97) มาก
- ❌ ถ้า SSR เล็กมากเทียบกับ SSE (X อธิบาย Y ได้น้อย) → F จะเล็ก และอาจต่ำกว่า F_critical → ไม่ปฏิเสธ H₀
- **ต่างกันตรง:** ต้องเทียบ F_cal กับ F_critical ที่คิดจาก df ไม่ใช่ดูแค่ว่า SSR มากกว่า SSE หรือไม่

**อย่าสับสน:** "F-test (ANOVA)" ในกรณี Simple Regression ทดสอบ β₁ เหมือน t-test ไม่ได้ทดสอบ β₀ และไม่ได้บอกทิศทางของ β₁

**เช็คความเข้าใจ:** จากตาราง ANOVA ข้างบน SSR = 1226.93 และ SST = 1600.90 โมเดลอธิบายความผันแปรของ Y ได้กี่เปอร์เซ็นต์ และ F ทำหน้าที่ตัดสินอะไร

<details><summary>เฉลย</summary>

1226.93 / 1600.90 ≈ 0.766 หรือประมาณ 76.6% ซึ่งสอดคล้องกับ R² ≈ 0.76 ในหัวข้อ 2.7 ส่วน F ทำหน้าที่ตัดสินว่า β₁ ≠ 0 หรือไม่ โดยเทียบ F_cal = 26.24 กับ F_critical = 5.32 ที่ α = 0.05 ได้ผลว่า X มีความสัมพันธ์เชิงเส้นกับ Y อย่างมีนัยสำคัญ
</details>

### 2.6 การทดสอบสมมติฐานเกี่ยวกับ β₀

การทดสอบว่ากราฟเส้นตรงผ่านจุดกำเนิด (Origin) หรือไม่

> 💡 **Intuition:** β₀ คือจุดที่เส้นตัดแกน Y ตอนที่ X = 0 ถ้าเส้นผ่านจุดกำเนิด (0, 0) แปลว่าเมื่อ X เป็นศูนย์ Y ก็เป็นศูนย์ด้วย ซึ่งไม่สมเหตุสมผลเสมอไปในโจทย์จริง การทดสอบ β₀ จึงถามว่า "ค่าคงที่ (intercept) ในสมการมีความหมายทางข้อมูลหรือไม่" จุดที่อุปมาจะพัง: β₀ ≈ 0 ทางสถิติ ไม่ได้แปลว่าโลกจริงไม่มีค่าคงที่เสมอไป ต้องดูว่า X = 0 มีความหมายในบริบทหรือไม่
> [Source: generated — not verified against original document]

**สมมติฐาน:**
- $H_0: \beta_0 = 0$ (กราฟเส้นตรงผ่านจุดกำเนิด)
- $H_1: \beta_0 \neq 0$ (กราฟเส้นตรงไม่ผ่านจุดกำเนิด)

**สถิติทดสอบ:**

$$t = \frac{b_0}{S_{b_0}}$$

**ผลการคำนวณจากตัวอย่าง:**

```
S²_b0 = 46.74 × (1/10 + (0.94²/0.444)) = 46.74 × (0.1 + 1.988) = 46.74 × 2.088 ≈ 97.63
S_b0 = √97.63 ≈ 9.88

t_cal = 46.48 / 9.88 = 4.70
t_critical (α=0.05, df=8) = 2.31

4.70 > 2.31  →  ปฏิเสธ H₀
สรุป: β₀ ≠ 0 กราฟเส้นตรงไม่ผ่านจุดกำเนิด ที่ระดับนัยสำคัญ 0.05
```

> **ถ้า $\beta_0 = 0$** จะได้สมการ: $\hat{Y} = b_1 X$ (ผ่านจุด Origin)

**🧭 ทำความเข้าใจ** _[Source: generated — not verified against original document]_

**แตกวลีสำคัญ:**
- "จุดกำเนิด (Origin)" → จุด (0, 0) ที่ X = 0 และ Y = 0 พร้อมกัน
- "$H_0: \beta_0 = 0$" → สมมติฐานว่าเส้นถดถอยผ่านจุดกำเนิด
- "$t = b_0 / S_{b_0}$" → ค่า intercept ที่คำนวณได้ เทียบกับความไม่แน่นอนของมัน

**ตัวอย่าง:**
- ✅ ตัวอย่างนี้ t_cal = 4.70 > 2.31 → ปฏิเสธ H₀ แปลว่า β₀ ≠ 0 เส้นไม่ผ่านจุดกำเนิด
- ❌ ถ้า t_cal เล็กกว่า 2.31 → ไม่ปฏิเสธ H₀ แปลว่าไม่มีหลักฐานพอว่า β₀ ≠ 0 ไม่ได้แปลว่า β₀ "เท่ากับ 0 แน่นอน"
- **ต่างกันตรง:** ต้องดูผลทดสอบทางสถิติ ไม่ใช่ดูกราฟเส้นด้วยตาเปล่าอย่างเดียว

**อย่าสับสน:** "β₀ = 0" ใน H₀ หมายถึงเส้นผ่านจุดกำเนิด ไม่ได้หมายถึง "ไม่มีความสัมพันธ์ระหว่าง X กับ Y" (การทดสอบนั้นคือ β₁)

**เช็คความเข้าใจ:** ถ้าผลทดสอบ β₀ ได้ "ไม่ปฏิเสธ H₀" ควรสรุปอย่างไรและห้ามสรุปอะไร

<details><summary>เฉลย</summary>

สรุปได้ว่าไม่มีหลักฐานเพียงพอว่าเส้นตัดแกน Y ห่างจากจุดกำเนิด จึงอาจใช้สมการ $\hat{Y} = b_1 X$ ได้ ห้ามสรุปว่า β₀ = 0 แน่นอน และห้ามสรุปเรื่องความสัมพันธ์ระหว่าง X กับ Y จากผลทดสอบนี้ (ต้องดูผล β₁)
</details>

### 2.7 สัมประสิทธิ์การตัดสินใจ R² (Coefficient of Determination)

> 💡 **Intuition:** ลองนึกว่า R² บอกเราว่า "โมเดล (เส้นตรง) ของเราสามารถจับความแปรปรวนของข้อมูลได้กี่เปอร์เซ็นต์" เช่น ถ้า R² = 0.76 หมายความว่า "76% ของการเปลี่ยนแปลงของ Y นั้นอธิบายได้โดย X ส่วนที่เหลือ 24% อาจเป็นเพราะปัจจัยอื่น ๆ ที่ไม่ได้คำนึงถึง หรือ random noise" R² สูง = เส้นอธิบายความแปรปรวนของ Y ได้มาก R² ต่ำ = X อธิบาย Y ได้น้อย (หรือความสัมพันธ์ไม่ใช่เส้นตรง)
> [Source: generated — not verified against original document]

**R²** คือสัดส่วนที่ตัวแปร X สามารถ **อธิบายการเปลี่ยนแปลงของตัวแปร Y** ได้

$$R^2 = \frac{SSR}{SST} = 1 - \frac{SSE}{SST}$$

**🧭 ทำความเข้าใจ** _[Source: generated — not verified against original document]_

**แตกวลีสำคัญ:**
- "SSR (Sum of Squares Regression)" → ผลบวกของ (ค่าคาดการณ์ - ค่าเฉลี่ย Y)² = ความแปรปรวนที่ Model อธิบายได้
- "SST (Sum of Squares Total)" → ผลบวกของ (ค่าจริง - ค่าเฉลี่ย Y)² = ความแปรปรวนรวมของ Y ทั้งหมด
- "R² = SSR / SST" → ส่วนแบ่ง (proportion) ของความแปรปรวนทั้งหมดที่โมเดลสามารถอธิบายได้

**ตัวอย่าง:**
- ✅ จากตัวอย่างยอดขาย Shampoo: R² = 1226.93 / 1600.9 = 0.766 → 76.6% ของความแปรปรวนของยอดขายอธิบายได้ด้วยค่าโฆษณา ส่วนที่เหลือ 23.4% มาจากปัจจัยอื่น → โมเดลค่อนข้างดี
- ❌ ถ้า R² = 0.05 → โมเดลอธิบายได้เพียง 5% → ส่วนใหญ่ของความแปรปรวนในข้อมูลมาจากสิ่งอื่น ไม่ใช่ X → โมเดลนี้ไม่ดี
- **ต่างกันตรง:** R² = 0.5 หมายความว่า "X อธิบายได้ 50%" ไม่ใช่ "X มีผล 50% ต่อ Y" (ตรงนี้มักสับสน)

**อย่าสับสน:** "R² = 0.9" ≠ "ทำนายค่า Y ได้ แม่นยำ 90%" — R² บอกว่า "อธิบายความแปรปรวนได้ 90%" ซึ่งต่างจากความแม่นยำของการทำนาย (prediction accuracy) ค่า R² สูง แต่ทำนายผิดได้ถ้าข้อมูลใหม่ต่างจากข้อมูลเก่า

**การตีความ:**

| ค่า R² | ความหมาย |
| :--- | :--- |
| R² → 1 | X อธิบายการเปลี่ยนแปลงของ Y ได้มาก (Model ดี) |
| R² → 0 | X อธิบายการเปลี่ยนแปลงของ Y ได้น้อย (Model ไม่ดี) |
| 0 ≤ R² ≤ 1 | ค่าเสมอ ไม่มีหน่วย |

**เช็คความเข้าใจ:** ถ้า R² = 0.64 และ R² = 0.81 (ทั้งสองโมเดลทำนาย Y ตัวเดียวกันจากข้อมูลชุดเดียวกัน) โมเดลไหนดีกว่า และแต่ละค่าบอกอะไร
<details><summary>เฉลย</summary>

โมเดลที่มี **R² = 0.81 ดีกว่า** เพราะว่า R² ที่สูงกว่า = อธิบายความแปรปรวนได้มากกว่า

- **R² = 0.64** → 64% ของความแปรปรวนใน Y อธิบายได้จาก X → 36% จาก factor อื่น
- **R² = 0.81** → 81% ของความแปรปรวนใน Y อธิบายได้จาก X → 19% จาก factor อื่น
- ส่วนต่างคือ 0.81 - 0.64 = 0.17 = 17 เปอร์เซ็นต์พอยต์ → โมเดล R²=0.81 ดีกว่า
</details>

**ผลการคำนวณจากตัวอย่าง:**

```
R² = SSR / SST = 1226.93 / 1600.9 = 0.766

→ ค่าโฆษณาทางวิทยุสามารถอธิบายการเปลี่ยนแปลงของยอดขายได้ 76.6%
```

## Part 3: Quick Reference & Exam Cheat Sheet

### Checklist สรุปขั้นตอนการวิเคราะห์ Simple Linear Regression

* [ ] **Step 1:** ตรวจสอบว่า X และ Y เป็นตัวแปรเชิงปริมาณ
* [ ] **Step 2:** เขียน Scatter Plot เพื่อดูรูปแบบความสัมพันธ์ว่าเป็นเชิงเส้นหรือไม่
* [ ] **Step 3:** ประมาณค่า $b_0$ และ $b_1$ ด้วย Least Squares Method
* [ ] **Step 4:** คำนวณสัมประสิทธิ์สหสัมพันธ์ R (Pearson Correlation)
* [ ] **Step 5:** ทดสอบ H₀: β₁ = 0 ด้วย t-test หรือ F-test (ANOVA)
* [ ] **Step 6:** ทดสอบ H₀: β₀ = 0 ด้วย t-test
* [ ] **Step 7:** คำนวณ R² เพื่อประเมินคุณภาพ Model
* [ ] **Step 8:** นำสมการที่ได้ไปพยากรณ์ค่า Y เมื่อรู้ค่า X

### สรุปสูตรสำคัญ

| สูตร | ความหมาย |
| :--- | :--- |
| $\hat{Y} = b_0 + b_1 X$ | สมการถดถอยเชิงเส้นอย่างง่าย |
| $b_1 = SS_{XY} / SS_{XX}$ | ความชันของสมการ |
| $b_0 = \bar{y} - b_1 \bar{x}$ | จุดตัดแกน Y |
| $R^2 = SSR / SST$ | สัดส่วนการอธิบายความแปรปรวนของ Y |
| $F = MSR / MSE$ | สถิติทดสอบ ANOVA |
| $t = b_1 / S_{b_1}$ | สถิติทดสอบสำหรับ β₁ |

## ⚠️ Common Pitfalls & Exam Traps

* **สับสน β₁ = 0 กับ ไม่มีความสัมพันธ์:** β₁ = 0 หมายถึงไม่มีความสัมพันธ์เชิงเส้นเท่านั้น ยังอาจมีความสัมพันธ์ในรูปแบบอื่น (Quadratic เป็นต้น)
* **ตีความ R² ผิด:** R² = 0.766 ≠ "X ทำให้ Y เพิ่ม 76.6%" แต่หมายถึง "X อธิบายความแปรปรวนของ Y ได้ 76.6%"
* **ลืมตรวจสอบ Scatter Plot ก่อน:** ถ้า X และ Y ไม่ได้มีความสัมพันธ์เชิงเส้น การใช้ Linear Regression จะให้ผลที่ผิดพลาด
* **สับสน b₀ กับ b₁:** b₀ คือจุดตัดแกน Y (intercept) ไม่ใช่ความชัน — b₁ คือ Slope ที่แสดงความสัมพันธ์
* **ปฏิเสธ H₀: β₀ = 0 ≠ β₀ มีค่ามาก:** การปฏิเสธแค่หมายความว่า β₀ ≠ 0 (กราฟไม่ผ่านจุดกำเนิด) ไม่ได้บอกว่ามากหรือน้อยแค่ไหน
* **ใช้ค่า Adjusted R² แทน R² เมื่อมี X หลายตัว:** R² จะเพิ่มขึ้นทุกครั้งที่เพิ่ม X แม้ X ตัวนั้นจะไม่มีประโยชน์ ควรดู Adjusted R² ใน Multiple Regression
